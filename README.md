# ワニのルールブック 🐊

「これは」と思った価値観を保存して育てる、自分ルール帳PWA。

- **三箇条**（最大3つの憲法）＋ **心得**（候補層）の二層構造
- 心得から三箇条へ昇格 / 卒業（理由付きアーカイブ）
- 今日の1本：心得から日替わりで1件表示
- データは端末のlocalStorageのみ（サーバーレス・非公開）
- Markdown / JSON エクスポートでお引越し可能
- PWA対応：ホーム画面に追加すればオフラインでも動く

## 開発

```bash
npm install
npm run dev
```

`main`へのpushでGitHub Pagesに自動デプロイされます。
